# 🌐 Web-developp – Plateforme de gestion des stages et candidatures

## 📌 Description
Ce projet est une application web développée en **PHP (orientée objet)** suivant une architecture **MVC (Model – View – Controller)**.  
Elle permet la gestion des **candidatures, entreprises, offres de stage, étudiants et pilotes**, avec une interface **dashboard** pour l’administration et des pages accessibles aux utilisateurs.

L’objectif est de proposer une plateforme centralisée pour la mise en relation entre **étudiants et entreprises**, ainsi que le suivi des stages par les pilotes et administrateurs.

---

## 🚀 Fonctionnalités principales
- 🔐 Authentification et gestion des utilisateurs (étudiants, pilotes, administrateurs)  
- 🏢 Gestion des entreprises (ajout, modification, suppression, affichage)  
- 📄 Gestion des offres de stage (création, édition, recherche, wishlist)  
- 👨‍🎓 Gestion des étudiants (profil, candidatures, suivi)  
- 📊 Tableau de bord et statistiques (stages, candidatures, entreprises)  
- 📬 Formulaire de contact et envoi de mails via **PHPMailer**  
- ⚙️ Administration complète via un dashboard  

---

## 🛠️ Technologies utilisées
- **PHP 8+** (Programmation orientée objet)  
- **MySQL** (gestion des données)  
- **HTML5 / CSS3 / JavaScript**  
- **Bootstrap** pour le design responsive  
- **PHPMailer** pour la gestion des emails  
- **Composer** pour la gestion des dépendances
